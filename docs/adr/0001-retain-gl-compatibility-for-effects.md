# Retain GL Compatibility when replacing the effect runtime

TacticsTemplateG will retain GL Compatibility when adopting ExMateria Effects. Engine-fold rendering is not required, and differences in visual appearance caused by its absence are acceptable; migrating to Forward+ to obtain engine-fold rendering is rejected.

This decision does not establish that the current addon supports GL Compatibility. Its native rendering path and dependencies must be verified separately; missing effects, shader failures, and gameplay regressions are not covered by the acceptance of visual differences. No addon port, engine-version change, or implementation strategy has yet been approved.
